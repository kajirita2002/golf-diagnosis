## イントロ（p4〜6）
- 目的: パワー・正確性・再現性。シンプルで合理的。生体力学とデータに基づく。
- 3つのゴール: 基準を理解して正しい方向性を持つ／再現性の高いスイングでコースで実践／**チェックポイントと練習ドリルで自分で評価し改善し続ける**。

## 基礎（p7〜15〜）: セットアップの4要素
1. グリップ（4P）: 握る位置（Placement）・手の向き（Position＝フェースの向きと軌道に直結。ニュートラル/ストロング/ウィーク）・強さ（Pressure。強すぎ→手首が硬くフェース操作が難しい、弱すぎ→インパクトでブレる）・毎回同じに握る（Precision）。
2. アライメント＆スタンス: 足・腰・肩の向き。スクエア＝ターゲットラインと平行（基準）。オープン（左向き）→アウトサイドイン・フェード寄り。クローズ（右向き）→インサイドアウト・ドロー寄り。
   - スタンス幅: ドライバー＝肩幅より広め、アイアン＝肩幅程度、ウェッジ＝やや狭め。広すぎ→右足体重・入射が緩い（シャロー）・回転が制限。狭すぎ→左体重・入射が鋭角・バランスを崩しやすい。
   - 体重: アイアンは左右 50/50〜やや左。前後はつま先・かかとに均等。つま先寄り→突っ込み・トップ/ダフリ。かかと寄り→起き上がり・フェース管理が難しい。手で振る人はかかと寄り、クラブを引きすぎる人はつま先寄りになりやすい。
3. ボール位置: 左右前後のずれが打点・方向・距離に影響。ショットに合わせて調整。
4. ポスチャー:
   - 背骨の角度: 股関節から前傾し背中はまっすぐ。猫背（軸がブレる）・反り腰（下半身が不安定）を避ける。
   - 膝: 軽く曲げる。伸ばしすぎ（バランスを崩す）・曲げすぎ（動きが制限）を避ける。
   - 腕（アームハング, p16）: 肩の力を抜き、腕は自然に垂らす。張りすぎ（テコが使えずヘッドスピードが上がらない）・強く握りすぎ（手首が硬い）を避ける。
   - 視線・首の角度（p17）: 視線の向きを整えると回転しやすく軸が安定。ボールの手前を凝視→ダフリ・インパクトで体重が右に残る。首を右に傾けボールを右から見すぎ→スイング中に右肩が下がる。（後方から見て頭が右に傾くのは×）
   - 力感（p18）: 肩・首・腕はリラックス、体幹と下半身は適度な張り。顎を少し上げ背骨と一直線。力みすぎ（ぎこちない）・脱力しすぎ（軸が不安定）を避ける。
5. ボール位置（p19）: 前後の位置は打点に、左右の位置は軌道・入射角・曲がりと縦距離に影響。ドライバー＝左足内側、ウッド＝左足内側からボール1〜2個右、ハイブリッド＝（左足内側から）さらに右、ロングアイアン＝スタンス中央からボール1〜2個左、ミドルアイアン＝中央〜ボール1個左、ショートアイアン＝中央〜少し右、ウェッジ＝中央〜ボール1個右。

## スイング理論（p20〜31）
- 最もやさしく打てるスイング＝ヘッドと手の余計な動きを抑え、**ニュートラルなプレーン**上でクラブを動かすシンプルなスイング（PGAスイング）。ヘッドの軌道と手の軌道を最もコントロールしやすい道に運ぶ。
- 3つの基盤（連動する）: ①回転の土台（安定した軸に沿った回転）②クラブヘッドの位置と向き（スイング中に適切に保つ）③体に対する手の位置＝**ハンドパス**（手の軌道がクラブを適切な軌道に運ぶ指標）。
- 構成する動き: 回転（腰・肩。ダウンの回転のタイミングと速さ）・軸の移動（大きくブレない。わずかな前後左右上下は起きる）・腕の振り（腕とヒジの角度がクラブ軌道に影響）・手首の角度（ヘッドの位置とフェースの向き）・足と脚（体重移動・膝の屈伸・地面を押す力）・ヘッドの動き。
- ニュートラルなプレーン: シャロー（鈍角）とスティープ（鋭角）の中間。偏りがないので一貫しやすい。
- 安定したスイング＝コントロール性の高さ:
  - クラブは重心がシャフト軸から外れているので、ダウンで加速すると開く（寝る）方向に回ろうとする → **P5 の位置で手でクラブを支え、P5 からクラブを立てて**（寝る動きを相殺）ヘッドをニュートラルなプレーンに乗せる（「P5から寝てしまう」×／「P5から立てる」○）。
  - 手元とクラブヘッドの連動: 手元がクラブを引っ張り、一定の方向へ先導する（トレーラーの例え）。
  - 安定を欠く挙動: スティープ（クロストップ・アップライトなトップ → クラブを立てて下ろし、インパクト直前で寝かせたり左に振り抜いて補正）／シャロー（挙動が大きく急な方向転換を含む）→ どちらも打球の方向と精度がばらつく。体・手・クラブの位置をニュートラルな範囲に収める。
- ハンドパス（p28〜）: スイング中の手の中心が描く軌道。**チェックポイントシステムでは手の位置が体のどの位置を通過しているかを確認**する。
  - 理想のループ: ダウンスイングで、バックスイングのハンドパスより**低い位置を通る「右ループ」**（ゴルファー視点で右回り）。急なスティープやクラブが寝すぎるミスを防ぐ。
  - 間違ったループ: 切り返しで手元が高い位置からそのままボール方向に降りる（アウトサイドイン）／ダウンで手元がバックスイングの軌道より極端に低く降りる（シャローすぎ・フェース管理が難しい）。
  - 修正の優先順位: ①まずハンドパスを整える（適切なループ）②次にシャフトの角度（手首の角度で決まる）。手の軌道が正しくなれば手首の動きも自然に安定。
- スイングの外観の重要性（p31）: 体の動きからイレギュラーな要素を減らしシンプルに。→ ここから「スイングの外観のチェックシステム」（= 04 チェックポイントシステム）へ続く。

## 04 チェックポイントシステム（p34〜。最重要）
- 考え方: 明確な評価基準（チェックポイント）で誰でも自分のスイングを正確に確かめられる。体型・筋力で違いはあるが、**上手い人は主要なポジションで同じ動きをしている**。撮った動画を漫然と見るのではなく、基準に照らして課題を洗い出し → 調整 → 再評価を繰り返す。
- 包括的な評価: 同じ前傾やシャフトの角度でも、**体に対する手の位置（インサイド/ニュートラル/アウトサイド）**が違えば別のスイング。3つの基盤をバランスよく。
  - 同じシャフト角度に見えても、手がニュートラルでなければ → **ハンドパスの改善**が必要。
  - 同じ手の位置に見えても、クラブ（ヘッド）がニュートラルでなければ → **手首の角度の改善**が必要。
- 撮る方向は2つ: **DTL（後方）** と **Face On（正面）**。各 P に両方の基準がある。「手の中心」＝両手の中心。

### Tips（アイアン）
- Take Away: ワンピース（クラブ・手・腕・肩を1つの塊で動かす。手だけで始動しない）／ウィズ（手と体の距離）を一定に（内側に引く・離しすぎを避ける）／トリガームーブ（左から右への体重移動で始動しヘッドを加速）。
- Back Swing: 十分な回転（腰45〜60°・肩90〜110°が理想。それ以上は不要）／ハンドパスに対するヘッドの位置（まずハンドパス、次にヘッドの位置とシャフト角）／アームストラクチャ（左腕を長く、右肘を畳みすぎず、半径を広く）。
- Half Way Down: ウィズの維持（手を体に引きつけずワイドに下ろす）／左側屈（切り返しで肩を開かず左側屈を少し強める → 右肩が落ちるエラーを防ぐ）／腕を下ろす（切り返しで体を開かずに腕を下ろす）。
- Impact: ハンドファースト（少し。過度は避ける）／手の高さ（前傾をキープして手が浮かない）／重心位置（インパクトの重心は約90%左足。右側屈が小さいほど重心が流れない）。

### チェックポイント使用例（p70）
- P5・P6 を スティープ／ニュートラル／シャロー の3つで比べる（例: P5 のシャフト角 6°＝スティープ、35°＝ニュートラル、58°＝シャロー）。スティープ → シャフトを寝かす・手はインに。シャロー → シャフトを立てる・手はアウトに。
- 見えているずれ（結果）を直したいときは、その**ひとつ前のポジション**に原因があることが多い。そこに至る動きの「入口」を変える。

## 05 スイングイシュー（p71〜86）: よくある問題のチェック方法
- エラー＝インパクト条件を満たすための「埋め合わせ動作」。一貫性は落ちるので避けたい。
- **スティープなシャフト角**: 許容範囲より鋭角。ダウン後半は適量のスティープニングが要るが量が重要。
  - アイアン後方: P5 = 30〜40° OK／29°以下 NO。P5.5 = シャフトが二の腕の中央〜前腕上部 OK／二の腕の中央より上 NO。P6 = ヘッドが手の周りボール1個分 OK／1個分以上 NO。P6.5 = 20〜30° OK／31°以上 NO。
- **アーリーリリース**: クラブヘッドの解放が早すぎて適正なインパクト条件（入射角）を作れない。左腕とシャフトのタメを維持。
  - アイアン正面: P6 = グリップエンドが左脚に収まる OK／左脚の外 NO。P6.5 = 手がへその前のとき15〜45°のシャフト角 OK／15°以下 or すでにインパクト後 NO。
- **アーリーエクステンション**: ダウンで骨盤がボール方向へ動く・起き上がる。プロでも骨盤はボール方向へ動くので見るのは**角度**。上半身の右傾も骨盤の後継。
  - 正面: P5・P6 = 骨盤と胸骨 0〜10° OK／10°以上 NO。後方: P5・P6 = 腰の角度145〜160° OK／160°以上 NO。
- **アーリーローテーション**: ダウン初期の腰の回転が大きすぎ。一気にではなく徐々に。
  - 後方: P5 = 左脚が右脚の右から半分見えている OK／左足が半分以下しか見えない・右脚の左サイドから見える NO。P6 = 左脚が右脚に隠れている OK／左脚が見える NO。P7 = 左脚が半分見えている OK／半分以上見える NO。
- **スエー**: 胸骨・骨盤の横移動（必ず起きる・パワー源だが量とタイミング）。計測: アドレスで胸骨から地面への垂直線と、骨盤の右側・左側からの垂直線を引く。
  - バック: P4 = 胸骨は二線の中央〜胸骨線の間、骨盤線よりボール1個分以内 OK／許容範囲外 NO。
  - ダウン: P5 = 胸骨は胸骨線上か1個左、左腰は左腰線上か1個左 OK。P7 = 胸骨は胸骨線よりボール1〜3個左、左骨盤は左骨盤線よりボール1〜2個左 OK。
- **右肘の外旋・内旋**（体に対する右肘の位置と角度）: アイアン後方の右肘の角度 OK範囲 P1 165〜175°／P2 155〜165°／P3 60〜70°／P4 0〜20°／P5 50〜60°／P6 125〜135°／P7 145〜155°。

## 06 パワーと飛距離（p87〜101）: アクティブバックスイング／キネマティックシーケンス（腰→胴・肩→腕→クラブ）／地面反力（横・縦・回転）／プレッシャーシフト（アドレス 左54・右46、トップ 右約75%、インパクト 左 ドライバー75%・アイアン83%。右シフト→ターン→左シフト→ターン）／リセンタリング（P1.5〜2で右へ動いた重心を P3〜4 で左へ戻す。アイアンで重要、ドライバーは抑えめ）。トップで右かかとに偏る→腰が早く水平に回る・右スエー、ダウンで急にツマ先へ→アーリーエクステンション。右ツマ先に偏る→手だけで上げ回転不足、ダウンでアウトサイドイン→スライス。
## 07 正確性と一貫性（p102〜118）: フェースコントロール（グリップ圧・手首は掌屈背屈が主・打ち出しはドライバー85〜90%/アイアン75〜80%がフェース）／スイングプレーンとクラブ軌道（クラブと体の同調・P4〜P5 でシャフトの角度を維持したまま腕を下ろす・P6 の左腕の角度（25°以上離れる＋ヘッドがインサイド＝NG、25°以内＋オンプレーン＝OK））／リズムとテンポ（バック:ダウン ドライバー 3:1・アイアン 2.8:1・ウェッジ 2.5:1・アプローチ 2:1・パター 2:1。メトロノーム・連続素振り・目を閉じる・ハーフスイング）／プレショットルーティン。
## 08 テクノロジー（p119〜127）: 動画分析（正面・後方の複数アングル、スロー再生、描画でハンドパスとシャフト角、チェックポイントと比べる）。
- チェックポイントリスト: 毎回同じ基準で見る。一度にすべて直さない（**1回の練習で1〜2項目**）。定期的に同じポイントで改善度を測る。
- ビフォー・アフター: **同じアングル・同じ条件**（背景・カメラの高さ）で撮る。スローで比べる。
- フィードバックループ: 撮影 → 分析（チェックリスト）→ 修正（改善ポイントを決めて調整）→ 再撮影 → 繰り返し（課題が解決するまで2〜4回）。一度の修正で大きな変化を期待しない。データとして残す。手本のスイングと比べる。
- 練習器具ドリル: アライメントスティックA（グリップ延長にセット、フォローで左腰〜脇腹に当たる：フェース向き・手首の使い方）／B（ベルトループに通す：腰と腕の同調、P6で手元がスティックに当たらない）／C（グリップ延長：シャフト角、P3でスティックがボールの内側を指す）／リストワーク（ゴムボールを両前腕に挟む）／ステップ（右足の外側を高く：スエー防止、右内側で支える）。

## 09 カスタム＆パーソナライズ（p133〜145）
- 球筋を決めるのはインパクト（フェースの向き＝打ち出しの75〜90%、クラブ軌道＝曲がり、打点＝ミート率・打ち出し・スピン、ダイナミックロフト＝高さ・スピン）。
- スイング動作は「起こりやすい傾向」でインパクトに影響するだけで、**確定ではなく可能性**（間接的要因）。同じ寝るでもフェースが開けばスライス、閉じればフック。動作から球筋は断定できない → 自分の傾向と球の傾向をセットで観察する。
- フェード・スライス系が出やすい特徴: 体（早く開く／体重移動が不十分で左に乗りきれない／回転中心が流れる＝スエー／手元が高い）、クラブ（シャフトが鋭角／ハンドパスがアウトサイド／アウトサイドイン軌道／フェースが開いたままインパクト／リリースが遅い＝ハンドレイト）、テンポ（ダウンが速すぎる／切り返しで上体や腕が主導／トップから鋭角に振り下ろしタイミングが合わない）。
- ドロー・フック系: 体（回転が遅れ気味・止まる／下半身より腕が先行＝手打ち／体重移動が早すぎて左に突っ込む）、クラブ（シャフト角が鈍角／ハンドパスがインサイド／インサイドアウト軌道／フェースが閉じてインパクト（早めに返る）／アーリーリリース・強いハンドアクション）、テンポ（トップで間がなく切り返しが早い／ダウンで力み腕が走る／フィニッシュが詰まる）。
- 球が上がりやすい: 体（アッパーブロー気味／体が起きる／右足体重のまま）、クラブ（ロフトを寝かせて使う／フェースが開いて当たる／ダウンブローが弱くすくい打ち）、テンポ（切り返しで体が止まって手が出る／インパクトで緩む）。
- 球が上がりにくい: 体（ダウンで上体が前や左に突っ込みハンドファーストが強い／手が先行しすぎロフトが立ちすぎ）、クラブ（ロフトが立ちすぎたインパクト／入射角がスティープで押さえつける当たり）、テンポ（テンポが速く切り返しで勢いがつきすぎ／ダウンで体が早く動きすぎ）。
- 持ち球: STEP1 何も意識せずノーマルショット → STEP2 傾向を探る → STEP3 持ち球を決めて調整。ドローなら許容範囲をシャロー寄り、フェードならスティープ寄りに（チェックポイントでニュートラルを目指したうえで）。

## 10 練習メニュー（p146〜155〜）
- 練習前に構成を決め、スイングの練習とターゲットを狙う練習に分け、**合計2〜3個の課題**をピックアップ、課題ごとに球数を決める。ドリルは段階的にフルスイングへ（スロー → 徐々にフルスピード）。
- ブロック練習（同じ動作の反復）: ウォームアップ（5〜15球）／テクニカル練習（20〜35球。終えたら球筋で結果の確認、スイング感覚の振り返り）／コピペ練習（素振り3〜4回 → 素振りの100%再現で打つ）／スタートライン練習（4m先のスティックを目安に打ち出し方向）。
- ランダム練習（順不同）: 9ボール（ドロー・ストレート・フェード×高中低）／集中力強化／アライメント練習／プレッシャー練習。
- 総合練習: スキルゲーム・スキルテスト（10球1セット、7/10成功で合格。ノートに記録して他の月と比較）。
- 練習メニューの作り方: 1球あたりの時間を測る → 時間配分（例 60分: ウォームアップ10・ショット30・ルーチン15・振り返り5）→ 球数配分（例 100球: ショット50・ルーチン30・課題ドリル20）。
- 練習ログ: 日付・場所・クラブごとの球数/距離/時間などを記録し比較。

## 11 スタートガイド（p158〜183。「American PGA Swing — ステップバイステップ」）
- How to Start の5ステップ: ①チェックポイントの理解 → ②スイングの撮影 → ③自己評価 → ④スイング分析 → ⑤課題の選定。
- 分析アプリ: 角度ツールと描画ツールがあれば何でもよい（例: OnForm・Swing Catalyst）。
- 撮影に必要なもの: 三脚＋スマホ用アタッチメント。定点から撮る（手ブレを防ぐ）。
- **カメラアングル**:
  - 後方（DTL）: 画面の中央の縦ラインがグリップエンドから手の中央の間にくる／中央の横ラインが腰骨の高さ（グリッド表示をONに）。よくあるミス＝左右の角度が付く → レンズがゴルファーの後ろにくるように。NG例: 縦ラインが左にずれる（カメラを右へ）／縦ラインが右・横ラインが腰骨より上（ボールとゴルファーの中央に縦ラインを合わせるのは NG）。
  - 正面（Face On）: 中央の縦ラインがスタンスの中央／中央の横ラインが腰骨の高さ。下からの煽りや上から見下ろしにならないよう、レンズを腹部の高さに。
- **ドミノ効果**: スイング前半の改善はスイング後半の大きな変化につながる（P1-P2 → P2-P3 → P4-P5 → P5-P6 → P6-P7。前ほど全体への効果が高い）。**P2 の修正 ＞ P6 の修正**。最初は **P2 のクラブヘッド位置**から始める。
- ケーススタディ P2 クラブヘッドポジション（DTL）: 許容範囲＝ヘッドの中心が手の周りボール1個分。
  - よくあるミス#1 ヘッドがインサイド: 原因は手首。左手のひらを地面へ向ける「回内」が早い＋多い → 改善: 左手の回内を「ゼロ」にする感覚でテイクバック、コツ: アッパーコック（橈屈）を追加（左手首はフラットのまま、右手首は少し背屈）。P3 まで左手首を右にねじる動作は抑える。
  - よくあるミス#2 ヘッドがアウトサイド: 原因は手首。「回外」（左手のひらを空へ向ける）が早い＋多い → 改善: 左手の回外を「ゼロ」にする感覚、アッパーコックを減らす（アドレスの手首の状態に追加しない）。
  - 調節の仕方: ①動画を見る前にまず自己評価（目標の動作ができたと思うか）②やり過ぎて逆側になったら、追加した感覚動作が「多い」ので次は少し減らす③まだ同じ側なら感覚が足りないのでより大胆に④次のスイングの前に「どの程度の感覚の調整が必要か」を整理してから。
  - 改善の目安: **10球テスト**＝撮影しながら10球打つ。課題以外に意識を向けない（当たり方・打点・行方は問わない。シャンクOK）。**合格基準＝10回中8回が許容範囲**。合格したら次の課題へ。
